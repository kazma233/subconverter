subconv

订阅链接生成器 · clash / loon / sing-box 连接后端…

每行一段，多行自动用 | 合并；http(s) 订阅与节点链接可混合。

url 必填：订阅地址或节点链接至少填一行。

预设地址只读展示（可选中复制）；选「自定义 URL…」后可编辑，留空 = 默认 Full。仅支持完整 http(s) URL。

正则为 Go RE2 语法：不支持 (?=…)、(?<=…) lookahead 与反向引用。

高级选项 · 节点处理与拉取

udp/tfo/scv 三态：选「按节点自身」= 不传参数，由节点链接自己决定。选「全局开/关」覆盖所有节点。
